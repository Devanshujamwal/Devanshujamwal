05 / Build notes

Implementation

01

Book model

book.py defines a Book class with ISBN, title, author, genre, and availability. Getters, setters, borrow_it(), and return_it() manage those values.

02

Catalogue operations

library_app.py contains loading, ISBN lookup, add/remove, menu, and save functions. The loader reads comma-separated records into Book objects.
